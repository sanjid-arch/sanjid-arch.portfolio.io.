# Sanjid Abdullah — Portfolio

A compact, responsive static portfolio built with plain HTML, CSS and JavaScript.

## Run locally

Open `index.html` in a browser, or use VS Code Live Server for local preview.

## Structure

- `index.html` — page content and section structure
- `styles.css` — responsive layout, blue/sky-blue themes, readable typography, full-page moving code texture and contact cards
- `script.js` — theme switcher, mobile navigation, scroll progress, full-page code parallax and reveal effects
- `assets/profile.jpg` — supplied portrait

## Before publishing

- Confirm the public phone number and email are the contact details you want to display.
- Add real project repository/demo links as projects become public. Current project cards are deliberately labelled as concepts, proposals or learning work rather than completed products.
- The reference URL could not be loaded by the browsing service during creation, so this follows the requested portfolio section structure and your design notes rather than claiming a pixel-identical recreation.
